## 📌 О проекте

**Starvell Assistant Bot** — это современное решение для автоматизации продаж, ведения чатов, выгрузки товаров и поднятия лотов на торговой площадке [Starvell.com](https://starvell.com). Управление ботом осуществляется в удобном режиме через Telegram-бота.

---

## ⚡ Ключевые возможности

* 💬 **Живой чат & Пересылка сообщений** — получайте сообщения с сайта Starvell прямо в Telegram и отвечайте клиентам не заходя на сайт.
* ⚡ **Авто-выдача товаров** — мгновенная передача ключей, аккаунтов, файлов или цифровых товаров покупателю сразу после оплаты.
* 🚀 **Авто-поднятие лотов** — автоматический запуск поднятия предложений в верх списка по расписанию.
* 📉 **Демпинг цен (Price Dumper)** — отслеживание минимальных цен конкурентов и автоматический сброс цен до заданного порога.
* 🤖 **Авто-ответчик** — гибкая система ответа на частые вопросы покупателей по триггерным словам.
* ⚡ **Быстрые ответы (Quick Replies)** — готовые шаблоны сообщений, отправляемые клиентам в 1 клик через инлайн-меню.
* ⭐ **Напоминалка про отзывы** — вежливые автоматические напоминания покупателям о необходимости оставить отзыв после выполнения заказа.
* 🧩 **Плагинная архитектура** — поддержка создания и подключения пользовательских плагинов.
* 📊 **Профиль и Статистика** — просмотр текущего баланса, холда, количества заказов и аналитики продаж.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/gadacy/starvell-assistant.git
cd starvell-assistant
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Вы можете запустить встроенный интерактивный мастер настройки:
```bash
python setup.py
```
Или создать конфигурационные файлы вручную из шаблонов:
```bash
cp .env.example .env
cp config.json.example config.json
```

Заполните ваши данные в файлах `.env` и `config.json`:
* `STARVELL_API_KEY` — авторизационная кука сессии с сайта Starvell.com.
* `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота (полученный от [@BotFather](https://t.me/BotFather)).
* `TELEGRAM_ADMIN_IDS` — ваш Telegram ID (получить можно у [@userinfobot](https://t.me/userinfobot)).

### 4. Запуск бота
```bash
python main.py
```
